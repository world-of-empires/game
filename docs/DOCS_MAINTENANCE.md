# Обновление документации

**Основное руководство:** [DEVELOPER_GUIDE.md](./DEVELOPER_GUIDE.md) — раздел «Как правильно зафиксировать изменения».

---

## Когда обновлять

| Событие | ARCHITECTURE.md | AI_CONTEXT.md |
|---------|-----------------|---------------|
| Новая папка/слой | ✅ | — |
| Изменение правил именования | ✅ | — |
| Новый модуль/зависимость | ✅ | — |
| Новый/изменённый/удалённый класс | — | ✅ |
| Новое свойство/метод в существующем классе | — | ✅ |
| Изменение API (сигнатура, поведение) | — | ✅ |

---

## Кратко

**Добавил новый код → обнови AI_CONTEXT.md.**  
**Поменял структуру проекта → обнови ARCHITECTURE.md.**

---

## При финализации (PROMPT_FINALIZE)

ИИ автоматически:
1. **Проверит и синхронизирует ARCHITECTURE.md** — сравнит реальную структуру `Source/WorldOfEmpires/` с документом и обновит при расхождениях (дерево каталогов, слои, «Куда помещать файлы», зависимости Build.cs)
2. Обновит **CHANGELOG.md** — по результатам git status
3. Обновит **ROADMAP.md** — текущая версия, таблица
4. Обновит **AI_CONTEXT.md** — новые классы/API, версия в конце
5. Обновит **VERSION** — новая версия
